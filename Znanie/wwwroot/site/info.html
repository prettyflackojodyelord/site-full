Путь заказа

Четыре понятных этапа

  1. Выберите книги

    Корзина хранится локально в вашем браузере.

  2. Заполните данные

    Форма проверяет имя, email, телефон и адрес.

  3. Получите демонстрационное подтверждение

    Данные не уходят на сервер — это честно обозначено в интерфейсе.

  4. После подключения API

    Заказ сможет перейти в ASP.NET backend и платёжный сервис.

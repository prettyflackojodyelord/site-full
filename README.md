# «Знание» — книжный магазин

Учебный проект книжного магазина: адаптивная витрина на HTML, CSS и JavaScript и приложение ASP.NET Core с каталогом книг в SQLite. В репозитории две версии интерфейса: статическая для GitHub Pages и копия внутри ASP.NET-проекта.

## Стек

- **Интерфейс:** HTML, CSS, JavaScript без фреймворков.
- **Сервер:** C#, ASP.NET Core и Razor Pages, целевая версия — .NET 8.
- **Данные:** SQLite и Entity Framework Core SQLite 8.0.11.
- **Хранение кода:** Git и GitHub. GitHub Pages публикует только статическую версию.

## Быстрый запуск ASP.NET-версии

Нужен .NET SDK 8 или совместимый SDK, способный собирать проекты `net8.0`. Из корня репозитория в PowerShell:

```powershell
cd Znanie
dotnet restore
dotnet run --urls "http://localhost:5005"
```

Открыть магазин: [http://localhost:5005/site/main.html](http://localhost:5005/site/main.html). Корневой адрес `/` пока показывает стандартную страницу Razor Pages, а не магазин. Остановить сервер — `Ctrl+C` в терминале. Если порт занят, остановите прежний процесс или укажите другой порт.

При первом запуске приложение создаёт `Znanie/znanie.db` и заполняет её книгами из `Znanie/Data/books.json`. Файл базы и каталоги `bin/`, `obj/` исключены из Git. Изменение `books.json` **не обновляет уже созданную базу**: это исходные данные только для создания новой БД. Для сохранения изменений существующей базы делайте резервную копию файла; не удаляйте его без необходимости.

## Как устроены данные

ASP.NET-версия работает так:

```text
SQLite (таблица Books)
  → StoreDbContext / Entity Framework Core
  → ASP.NET Core: /api/catalog.js
  → window.BOOKS и window.GENRES
  → app.js → каталог, карточки и остальные разделы
```

- `Znanie/Data/Book.cs` — модель книги, включая идентификатор, жанр, цену, описание и ссылку на обложку.
- `Znanie/Data/StoreDbContext.cs` — контекст EF Core с `DbSet<Book>`.
- `Znanie/Data/books.json` — книги для начального заполнения новой базы.
- `Znanie/Data/genres.json` — данные жанров; сейчас они читаются из JSON, а не из БД.
- `Znanie/Program.cs` — настройка SQLite, начальное заполнение, API и маршруты Razor Pages.

Приложение использует `EnsureCreated`, миграции EF Core пока не настроены. Перед изменением модели и схемы существующей базы нужно продумать миграцию данных: изменение класса само по себе схему не обновит.

## API

| Запрос | Результат |
| --- | --- |
| `GET /api/books` | JSON со всеми книгами, сортировка по названию. |
| `GET /api/books/{id}` | JSON книги по идентификатору или `404`, если она не найдена. Пример: `/api/books/1984`. |
| `GET /api/catalog.js` | JavaScript с `window.BOOKS` из базы и `window.GENRES` из JSON; его подключают страницы ASP.NET-версии. |

API пока предназначен только для чтения: добавления, изменения и удаления книг через него нет. Фильтрация, сортировка и поиск выполняются в браузере по загруженным данным. Обложки задаются путями к файлам проекта или внешними ссылками на Open Library; внешние изображения зависят от доступности сервиса.

## Статическая версия и GitHub Pages

Папка `site/` — отдельная копия витрины. Она получает данные напрямую из `site/assets/js/books.js`, без C#, API и SQLite. Из корня репозитория её можно запустить локально:

```powershell
py -m http.server 8000
```

Откройте [http://localhost:8000/](http://localhost:8000/); корневой `index.html` перенаправляет на главную. Для GitHub Pages в настройках репозитория выберите публикацию из ветки `main`, папка `/ (root)`.

**Важно:** GitHub Pages не запускает ASP.NET Core. Данные статической версии и SQLite не синхронизируются автоматически. Правки интерфейса могут потребоваться в обеих копиях: `site/` и `Znanie/wwwroot/site/`. При переносе страниц сохраняйте различие подключения данных: `assets/js/books.js` в статической версии и `/api/catalog.js` в ASP.NET-версии.

## Структура интерфейса

Обе копии содержат одинаковые основные страницы:

- `main.html` — главная, подборки и баннер карт.
- `index.html` — каталог с фильтрами и сортировкой.
- `category.html?genre=...`, `product.html?id=...`, `search.html?q=...` — жанр, книга и поиск.
- `favorites.html`, `cart.html`, `checkout.html` — избранное, корзина и форма заказа.
- `cards.html` — предложения скидочных карт.
- `about.html`, `contacts.html`, `info.html` — информация о магазине, контакты, оплата и доставка.

Общие стили находятся в `assets/css/styles.css`, интерфейс и поведение — в `assets/js/app.js`, логика кнопок карт — в `assets/js/cards.js`. Шапка и подвал создаются в `app.js`, поэтому их изменения отражаются на всех страницах соответствующей копии.

## Что работает и что предстоит сделать

- Корзина и избранное сохраняются в `localStorage` браузера (`znanie-cart-v1` и `znanie-favorites-v1`), без учётной записи и синхронизации.
- Формы проверяют поля локально. Реальной отправки сообщения, сохранения заказа и оплаты нет; демонстрационное оформление очищает локальную корзину после успешной проверки.
- Админка, авторизация, серверное редактирование книг, учёт остатков и история заказов ещё не реализованы. Razor Pages пока содержит страницы шаблона.
- Рейтинги, отзывы, цены, наличие, контакты и часть условий — данные учебного проекта; не следует считать их подтверждёнными сведениями реального магазина.
- Скидочные карты представлены как предложения: оформление пока не подключено.

Для дальнейшей работы над админкой понадобится CRUD книг, проверка данных на сервере, а также авторизация и ограничение доступа к административным действиям. Перед публикацией ASP.NET-версии потребуется хостинг с поддержкой .NET и постоянное хранилище для SQLite.

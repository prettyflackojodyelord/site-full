# «Знание» — многостраничный книжный магазин

Адаптивная статическая витрина на HTML5, CSS3 и Vanilla JavaScript. Дизайн развивает визуальную систему приложенного макета Figma: графитовый фон, тёплый кремовый акцент, классическая типографика и обложки из исходных материалов.

## Страницы

- `site/main.html` — содержательная главная: первый экран, жанры, карусели, подборки и преимущества.
- `site/index.html` — каталог из 31 книги с совместными фильтрами и сортировкой.
- `site/category.html?genre=...` — отдельная жанровая подборка.
- `site/product.html?id=...` — динамическая страница книги с характеристиками, отзывами и похожими книгами.
- `site/search.html?q=...` — поиск и состояние «ничего не найдено».
- `site/favorites.html` — избранное.
- `site/cart.html` — корзина с изменением количества, удалением и пересчётом.
- `site/checkout.html` — демонстрационное оформление с валидацией.
- `site/about.html` — о проекте и форма обратной связи.
- `site/contacts.html` — контактные ссылки.
- `site/info.html` — оплата и доставка.

Исходные маршруты `main.html`, `index.html`, `product.html` и `info.html` сохранены.

## Что работает

- фильтры по жанру, цене и году первого издания;
- сортировка по цене, году, рейтингу и названию;
- поиск по названию, автору и жанру;
- корзина и избранное на `localStorage`;
- изменение количества и пересчёт суммы/доставки;
- жанровые страницы и связанные карточки;
- адаптивные карусели, мобильное меню и клавиатурный фокус;
- проверка `text`, `email`, `tel`, `textarea` и `checkbox` в формах;
- понятные пустые состояния и демонстрационные сообщения об успехе;
- поддержка `prefers-reduced-motion`.

## Локальный запуск

Из корня репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Корневой `index.html` перенаправит на `site/main.html`.

Можно использовать любой другой статический сервер. Открытие файлов напрямую через `file://` не рекомендуется из-за различий в политике браузеров.

## GitHub Pages

1. Загрузите репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.
5. Сохраните настройку и дождитесь публикации.

Все ссылки и ресурсы относительные, поэтому сайт работает и в подпапке репозитория GitHub Pages.

## Демонстрационные данные и ограничения

- Цены, рейтинги, наличие, отзывы, условия доставки и часть характеристик — демонстрационные.
- Годы в каталоге обозначают первое издание произведения, а не конкретный товарный тираж.
- Часть обложек взята из предоставленного Figma-файла; для остальных интерфейс создаёт подписанные демонстрационные обложки.
- Формы валидируются локально, но не отправляют данные.
- Нет авторизации, базы данных, реальной оплаты, остатка товара, истории заказов и серверной синхронизации корзины.
- Телефон сохранён из исходного проекта. Email `hello@example.com` явно демонстрационный; реальные адрес и соцсети не выдумывались.

## Перенос на React + ASP.NET

1. Перенести `books.js` в JSON/API-модель `Book` и получать каталог через ASP.NET endpoint.
2. Разделить интерфейс на `SiteHeader`, `BookCard`, `BookGrid`, `Filters`, `CartSummary`, `FormField` и страницы маршрутов.
3. Перенести чистые функции фильтрации/сортировки в сервис или React hooks.
4. Заменить `localStorage` корзины на пользовательскую корзину API с локальным fallback.
5. Подключить серверную валидацию, idempotency для заказа и платёжный провайдер.
6. Хранить контакты, стоимость доставки и контентные блоки в конфигурации/CMS, а не в разметке.
